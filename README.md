# 四角形迷路チャレンジ

ブラウザ上で動く日本語対応の迷路ゲームです。単一のHTMLファイル(`index.html`)のみで構成され、外部ライブラリ・外部API・データベース・画像素材には一切依存しません。

**▶ そのまま遊べる公開URL: [https://kokosan60.github.io/maze-challenge/](https://kokosan60.github.io/maze-challenge/)**

ローカルでも `index.html` をブラウザで開くだけで動作します(サーバー不要)。

## 概要

- **スタートは左上(S)、ゴールは右下(G)**。一本だけの正解ルートを探して進みます
- **一意解保証**： 正解ルートが1通りしかない迷路だけを表示します(検証に失敗した迷路は破棄して自動再生成)
- **自由なサイズ指定**： 縦・横それぞれ 2〜200 セルで指定できます(初期は15×25)。最大200×200=4万セルでも生成はミリ秒単位
- **手動操作**(キーボード・方向ボタン・スワイプ)と**自動解答**、**リセット**、**新しい迷路の生成**、**迷路画像のPNG保存**に対応
- 手数・経過時間・最短手数・検証状態を常時表示し、クリア時には実際の手数と最短手数の差を評価
- PC・スマートフォン両対応のレスポンシブUI(アニメーション縮小設定 `prefers-reduced-motion` にも対応)

## 使い方

### 移動

| 操作 | 内容 |
|---|---|
| `↑` `↓` `←` `→` または `W` `A` `S` `D` | 上下左右へ移動 |
| 画面の方向ボタン(十字キー) | タップ / クリックで移動 |
| 迷路の上をスワイプ | スワイプ方向へ移動 |

壁の方向・迷路の外へは移動できません(手数も加算されません)。タイマーは**最初の有効な移動**で開始します。

### ボタン

| ボタン | 動作 |
|---|---|
| **サイズを変更** | 入力欄の縦・横の値で迷路を作り直します。入力欄を変更しただけでは迷路は変わらず、このボタンでのみ適用されます |
| **新しい迷路** | **現在と同じサイズ**の迷路を新しく作り直します(未適用の入力値は使いません) |
| **現在の迷路をリセット** | 迷路はそのままに、プレイヤー・手数・時間・軌跡・解答表示を初期化します |
| **自動解答** | 正解ルート(solutionPath)を1セルずつアニメーション表示します。完了後、最短手数を表示します |
| **自動解答を停止** | アニメーションを中断し、続きからプレイできます |
| **迷路画像を保存** | 現在の表示状態(正解経路の表示 / 非表示どちらでも)のままPNGでダウンロードします |

クリアすると、実際の手数・経過時間・最短手数・その差とともに「クリア！」が表示され、「もう一度挑戦」(同じ迷路でリトライ)か「新しい迷路」を選べます。

## 迷路生成の仕組み

### 生成： ランダム化深さ優先探索法(穴掘り法)

内部は「壁を含まない論理セル」の長方形(行・列とも0起点)として管理し、各セルが上下左右の壁情報をビットフラグで持ちます。

1. すべてのセルを未訪問、すべてのセル間の壁を閉じた状態にする
2. スタートセル(左上)を起点として訪問済みにし、**明示的な配列スタック**へ追加する(再帰は使わない)
3. スタック末尾のセルを現在セルにし、隣接する未訪問セルを列挙して**毎回シャッフル**
4. 候補があれば1つ選んで壁を取り除き(掘削)、訪問済みにしてスタックへ追加
5. 候補がなければスタック末尾を削除して直前の分岐点へ戻る
6. スタックが空になるまで繰り返す

未訪問セルへの接続時だけ壁を取り除くため、生成中に閉路は作られず、全セルが連結な**木構造(内部通路 = セル数 − 1 本)**になります。

### 検証： 表示前に一意解を保証

`validateMaze()` が生成直後(生成時検証)と描画直前(生成後検証)の2回実行され、次の**すべて**を満たす迷路だけが表示されます。

| 条件 | 意味 |
|---|---|
| `visitedCount === cellCount` | 全セル到達可能(未訪問セルなし) |
| `edgeCount === cellCount - 1` | 余分な通路がない(木構造) |
| `reachable === true` | スタートからBFS/DFSで全セルへ到達できる |
| `startToGoalReachable === true` | スタートからゴールへ到達できる |
| `solutionCount === 1` | スタート→ゴールの**単純経路がちょうど1本**(現在の探索経路だけを`pathVisited`で管理するDFSで数え、2個見つけた時点で打ち切り) |
| `isTree === true` | 連結・辺数=セル数−1・親以外の既訪問セルへ接続する辺がない=閉路なし |

すべて合格した場合のみ `isUnique = true` となり、「✓ 一意解を確認済み」バッジ付きで表示されます。失敗した迷路は画面に表示せず破棄し、最大100回まで自動的に再生成します(それでも失敗した場合は、迷路サイズ・セル数・通路数・訪問セル数・到達性・閉路の有無・経路数を含むエラーを表示)。

### 正解ルートの復元

BFS(幅優先探索)で `dist` 配列を未訪問値 −1 で初期化し、セルをキューへ入れる時点で `dist` と `parent` を確定します。ゴール到達で探索を打ち切り、`parent` を逆向きにたどって反転し、**先頭=スタート・末尾=ゴール**の `solutionPath` を作ります。この1本の経路を最短手数表示・自動解答・クリア判定で共有するため、機能ごとに別の経路が表示されることはありません。

## 技術構成

- HTML + CSS + JavaScript(バニラ、単一ファイル、フレームワークなし)
- 迷路データ: `Uint8Array` の壁ビットフラグ。迷路データ / プレイヤー位置 / 検証結果 / 表示状態を分離して管理
- 描画: Canvas(静的部分はオフスクリーンキャンバスにキャッシュし、大規模迷路でもアニメーションを軽量化)
- 経路数カウントDFSは明示的スタックの反復実装で、200×200でも再帰深さの制限を受けない
